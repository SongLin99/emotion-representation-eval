# Qwen2.5-14B-Instruct evaluation

Checkpoint: `Qwen/Qwen2.5-14B-Instruct`, revision
`cf98f3b3bbb457ad9e2bb7baf9a0125b6b88caa8`.
Primary state L36 was fixed before measurement, matching Olmo L24 at 75% relative depth.
The four-criterion evaluation is single-layer; released vectors cover all 49 states.

## Materials and vectors

The evaluation uses the corrected bilingual materials in `data/revisions/20261004/`.
Vector construction uses the existing 6,000 emotion stories and 1,000 matched-neutral
stories, with the same topic-balanced difference, neutral-PCA removal and unit normalization.
Raw story inputs use token50-inclusive FP32 pooling after BF16/SDPA forward passes.
L0 is the embedding, L1–47 are block outputs, and L48 is the final-normalized state.

Vectors in `vectors/qwen25_14b_instruct/{en,zh}/emotion_vectors.safetensors`
contain `means`, `matched_neutral_means`, `raw`, `vectors` and `unit_vectors`, each
with shape `[49, 6, 5120]`. The order is happiness, surprise, fear, disgust, anger, sadness.
Extraction/PCA code and activation caches remain outside this evaluation repository.

Qwen Chinese tokenization leaves 270 of the 1,128 frozen PCA candidates too short.
Both languages exclude those IDs, leaving 858 paired texts. The exclusion record is
`data/vector_construction/qwen25_14b_pca_exclusions_20261004.json`. Olmo vectors
still use 1,128 pairs. Published manifests retain the original extraction provenance.

## Readout coverage

All 5,000 rows remain in `readouts_l36.csv`: 3,100 token50 rows and 1,900
continuation-only rows. Both vector languages are evaluated on each state.
Five Chinese token50 inputs are explicitly missing, with blank scores and reasons:

- Originals: `fear_T18_L0`, `disgust_T12_L0`, `anger_T04_L2`.
- Paraphrases: `anger_T04_L0`, `anger_T04_L2`.

Primary sensitivity uses complete five-level ladders per language: 120 English and
117 Chinese. A supplementary analysis uses the same 117 bilingual ladders.
Invariance requires all four original/paraphrase and English/Chinese conditions:
596/600 IDs remain. No text was padded, rewritten or selected by its measured score.

## Generation and scoring

The fixed edit is `h_new = h + alpha * N * unit_direction`, with
`N = 355.8481024546985`. N is the mean individual-token L2 norm over **all valid tokens**
of the English Qwen PCA neutral corpus at L36, shared across prompt/vector languages.
`neutral_token_norms.json` provides the original norm statistics in each vector folder.
Only the final assistant boundary in prefill and subsequent cached decode positions
are edited. The native Qwen chat template adds its default system message; native
generation settings are retained, with `do_sample=False` for greedy decoding.

- Ordinary English: 300 answers, ±0.5, maximum 180 new tokens, including six equal-norm
  random directions orthogonal to the six English emotion directions.
- Cross-language: 600 answers, four prompt/vector language combinations, ±0.5,
  maximum 320 new tokens.
- Smaller dose: 1,176 answers, the same four combinations at ±0.1 and ±0.25,
  maximum 320 new tokens.

Responses preserve token IDs, rendered chat, actual batch sizes and edit norms.
Scoring uses anonymous shuffled IDs and only prompt/response content, through
`deepseek/deepseek-v4-flash-0731`, temperature 0.35, top_p 0.9 and the quality-v2 rubric.
One cross-language and seven small-dose invalid score schemas were re-scored individually
with the same model and core rubric. First valid scores remain; no clipping or filling
was used. Recovery records are in the results directory; raw API caches remain local.

Full and quality-valid signed-pair effects are both reported. Both endpoints must
have no replacement characters or token-limit hit, requested-script fraction ≥0.5,
and coherence/task/language scores ≥3. Intervals resample prompts, rather than treating
all answers as independent. Quality subsets may be selected and do not replace full effects.

The first English microbatch's two zero-dose answers were independently regenerated
without hooks and match token for token. This is an implementation check, not a
full audit of all baselines or their language quality.

## Offline reproduction

```bash
pip install -r requirements.txt
python -m evaluation.qwen_summary --output outputs/qwen_recomputed_summary.json
python scripts/verify_updated_benchmarks.py
python scripts/verify_release.py
```

The first command recomputes the complete summary from frozen readouts and judged
answers, including eligibility, bootstrap intervals, robustness and dose/quality results.
It requires neither model weights nor API access and refuses to overwrite outputs.
The verifier compares the complete recomputed Olmo and Qwen summaries with their archives.

The public GPU runners are Olmo-specific. Qwen's original inference driver remains in
the research workspace; this release provides precomputed vectors, frozen outputs,
protocol and offline metric reproduction, not a portable full Qwen GPU rerun.
Absolute paths in the frozen protocol are historical provenance, not prerequisites
for running the offline commands.

## Results and limits

English/Chinese target–neutral AUROC is 0.867/0.856; intensity mean rho is
0.646/0.614; paraphrase rho is 0.893/0.847. Exact per-emotion metrics and intervals
are in `results/qwen25_14b_20261004/summary.json`.

Ordinary English ±0.5 target delta is 0.375, CI95 [0.208, 0.597], but quality-valid
coverage is 0/72. Cross-language ±0.5 coverage is also zero in all four combinations.
Small-dose coverage reaches only 9/72. Stable, quality-preserving control is not established.

Comparisons include different PCA subsets, token eligibility, native chat defaults,
generation settings and fixed norms. These are not isolated architecture effects.
AI-assisted materials and a single-model judge are not independent human validation.
Expression changes do not establish subjective emotion or introspection.
